## 2. 开发纪律(强制)

1. **按批次推进**:Sprint-0 预研闸门(PKG-01~07,9.5 人日,**三项预研结论未出不得进 B1**)→ B1 P0 基础面(PKG-08/09/13)→ B2 P0 核心引擎(PKG-10/12/14/17/18)→ B3 P0 体验闭环(PKG-11/15/16/19/20/21/22)→ B4 P1 增强闭环(PKG-23~26)→ B5 P2+SIT/上架(PKG-27+专项 12 人日)。**每批过「DoD 六条」(移交包 §3.2:构建绿/核心纯逻辑单测 ≥70%/UI 原型一致性走查/真机 ≥3 机型冒烟/P0 一句线录屏/P0-P1 缺陷清零)并经监督者签字后才进下一批**,禁止跳批。
2. **docs/ 与 UI/ 只读**:它们是规格与复现基准。发现矛盾或缺口 → **停止并上报监督者**,禁止自行修改规格文档迁就代码。
3. **需求变更走主项目**:任何变更必须回到 `D:\createIdear\Framework\projects\VR\` 由项目经理修订并重新下发;代码仓内不做口头变更。**预研触发的既定预案除外,按移交包执行并在 dev-log 记录**:①PR-1 锚定不达标 → GPS+罗盘降级基线已是既定口径(RA-2/D-022);②PR-3 Meshy 大陆不可达 → 切 Rodin 乙案(D-024,网关抽象已留缝);③PR-2 高德 SDK 聚合不足 → 服务端 geohash 网格聚合降级(feature-list FR-01 行)。
4. **代码布局**:`client/`(Unity + AR Foundation 工程)、`server/`(NestJS monorepo:api + worker + 共享类型)、`admin/`(AntD Pro);构建产物不入库(见 .gitignore);**版本锁定移交包 §2 清单,不追新**。
5. **⚠ 假设按标注时点校验**(移交包假设分组):Sprint-0 必出 PR-1/PR-2/PR-3 书面结论(可行/降级),并触发复审卡 RA-2/RA-4 判定(偏差 >±5 人日升级主项目,D-041);其余随所属批次验证。
6. **每批结束登记 `dev-log.md`**:实耗 token(输入/输出)/会话轮次/有效代码行/DoD 结果——数据回填主项目台账,校准 A-615(token/行)与 A-616(输入输出比),不登记=批次未完成。
7. **决策红线(代码层不可违背)**:全 App **零购买按钮/零充值入口**(D-023,套餐页仅「即将开放」);Token 只显示数值不折算人民币(D-029);生成价 60 Token/次、注册赠 80(D-047/049);积分单向抵扣不可购生成(D-009);敏感权限逐项单独同意(D-031);分享水印二维码「扫码回到这里」(D-021)。
