D-063 产品级六维打磨(本轮增量):① 系统级仿真——每屏状态栏 + 底部手势条,S8/S32 键盘弹层态,S12/S16/S19 放置/保存成功 Toast;② 图标体系统一——emoji 锚(🗿/🖼️/💬)全部替换为 FontAwesome(模型 fa-cube / 图片 fa-image / 文字 fa-comment-dots),勋章与功能入口同步,仅保留少量描边化装饰贴纸;③ 内容真实化——人名/标题/相对+绝对时间/规范距离/变异数字,列表屏 6-8 条起;④ 地图细节——西湖水系/绿地/主次路网分级/路名(南山路·西湖大道·延安路)/POI 小点,贴纸针仍是主角;⑤ AR 舞台 HUD——三分取景网格/对焦框/测光 EV hint/REC 角标(浏览态不用)+ 双色氛围光;⑥ 一致性——全站 2px 墨描边、硬阴影右下 4px、间距 4 的倍数、图片换更贴场景的城市街景/公园/夜景直链(range GET 206 验证)。
Zenly 解构 → 本产品落法(得其神,不照抄):① 贴纸/模因化 → 内容卡与成就徽章贴纸化(墨描边+硬偏移阴影+微旋转);② 平涂撞色+黑描边 → 三色平涂分区卡 + 全站 2px 墨边,渐变收缩为霓虹强调(凸起相机钮/AR 深色舞台/加载);③ 超大字强对比 → 展示字层 44/32(余额/百分比/倒计时);④ 地图即社交场 → 内容标记为「贴纸针」(emoji+条数徽标),奶油底卡通地图;⑤ 手势优先+底部弹层 → 第三层一律圆角 28 底部弹层;⑥ 深色模式+霓虹 → AR 取景流为深色舞台+珊瑚霓虹,与暖白纸面构成「纸面↔舞台」双世界。解构来源:TechCrunch 2022 改版评测、人人都是产品经理 5.0 拆解、UX Collective 案例研究、Mobbin 档案(详见 docs/05-uiux/ui-spec.md §6.0)。
