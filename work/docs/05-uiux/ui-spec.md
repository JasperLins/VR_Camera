## 📌 文档头契约(下游先读这节)

- **关键结论**(≤5 条):

## 6. UI 风格定义

### 6.0 Zenly 设计语言解构(先研究后设计,D-059)

**研究来源**(2026-08-22 检索):
1. TechCrunch《How Zenly made social maps cool again, and what's next》(2022-04-22)——5.0 改版一手评测:黑底界面、霓虹灯式主按钮、地图永久黄橙色叠层、策略游戏式足迹可视化、底部三键 + 中央键上滑会话列表;
2. 人人都是产品经理《全球爆火应用 Zenly 5.0 大改版,有哪些设计细节值得学习?》——四大维度拆解:视觉(超级大字号、多巴胺撞色渐变)、动效(Q 弹挤压拉伸、迪士尼 12 原则、全程反馈)、玩法(表情雨、解锁成就、App 图标收集)、彩蛋(超远导航彩蛋等);
3. UX Collective《The Zenly Experience — a product case study》(Josh Nelson)——「playful copy + big font + dynamic cursor」的引导调性、加好友触发 emoji 掉落、品牌 3D 插画;
4. Mobbin Zenly 档案(屏幕/品牌色板:黑、白 + 高饱和 Christi 绿等)——底部弹层、头像标记、欢迎页「LET'S GO」;
5. 出海参考《实时定位社交 App 遍地开花》+ 腾讯云开发者社区——模仿者(Jagat)继承其标志性撞色 UI;Zenly 团队续作 Amo/Bump 延续设计血统。

**提炼的六条可迁移特征 → 本产品落法**(得其神不照抄像素):

| # | Zenly 特征 | 本产品移植(D-059) |
|---|---|---|
| Z1 | 贴纸/模因化:emoji 即货币、贴纸卡、成就徽章、表情雨 | 内容卡/成就/徽章全部**贴纸化**:白底 + 2px 墨描边 + 硬偏移阴影 + 微旋转;打卡成就 = 圆形贴纸勋章(内虚线环);空状态 = 大 emoji 贴纸 + 幽默文案 |
| Z2 | 大胆平涂撞色 + 黑描边(深底霓虹) | 常规页**平涂撞色块**(日落黄/天青/珊瑚软底分区卡)+ 全站 2px 墨描边;渐变收缩为霓虹强调(相机钮/AR 舞台/加载) |
| Z3 | 超大字号与强对比(playful copy + big font) | 新增展示字层 32–44(余额大字/百分比/倒计时/启动标语)与 12px 标签强对比;文案口吻年轻直给 |
| Z4 | 地图即社交场(地图第一公民、好友头像即标记、黄橙叠层、足迹可视化) | 内容标记 = **贴纸针**(胖圆角方块 + emoji + 条数徽标 + 墨描边白边);地图奶油底 + 白路网 + 贴纸微建筑;足迹时间线 = 拍立得贴纸墙 |
| Z5 | 手势优先 + 底部弹层(中央键上滑列表、胖圆浮钮) | 第三层一律底部弹层(圆角 28 + 抓手条);主操作胖圆按钮带墨描边与按压位移 |
| Z6 | 深色模式地图/界面 + 霓虹按钮(5.0) | AR 取景流 = 深色舞台 + 珊瑚霓虹强调(A-711 微调),与常规暖白纸底形成「纸面↔舞台」双世界 |

**明确不迁移**:Zenly 的实时好友位置流(本产品无 LBS 好友轨迹,隐私边界不同)、持续后台定位相关交互、纯娱乐性 App 图标收集玩法(仅保留轻量成就贴纸)。

### 6.1 设计关键词(5 个,v0.3)

1. **贴纸拼贴**——界面像一本可以贴贴纸的手帐:贴纸卡(墨描边 + 硬阴影 + ±2° 微旋转)、emoji 贴纸标记、成就贴纸勋章,年轻、可收集、有手作感;
2. **平涂撞色**——日落黄/天青/珊瑚三色平涂色块大胆分区,配 2px 墨描边收边;渐变只在「霓虹强调」三处出现(相机钮/AR 舞台/加载);
3. **超大字强对比**——展示字 32–44 与 11px 间距标签同屏对话,数字(余额/进度/倒计时)是页面主角;
4. **地图即社交场**——地图是第一公民:贴纸针 + 条数徽标 + 聚合胶囊 + 呼吸定位点,「附近有什么」一眼可读;
5. **纸面↔舞台双世界**——常规页 = 暖白纸底 + 贴纸;AR 相机流 = 深色舞台 + 珊瑚霓虹;进出 AR 即换世界,心智清晰。

- **参考风格**:Zenly 5.0(贴纸/撞色/大字/深底霓虹,§6.0 来源 1/2)、Amo·Bump(Zenly 血统延续,来源 5)、Snap Map 头像即标记(来源 5 佐证社交地图惯例)、iOS 17(SF Symbols 语义、44px 触控、Home Indicator)。

### 7.2 字体

- 字体族:`-apple-system, "SF Pro Text", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`(不引入网络字体)。
- 字号层级(基线沿用 ux-flows §5.4:**新增展示字层**,见 A-721):展示字 44/32(仅余额大字、生成百分比、倒计时、启动标语,`font-weight:900`)— 大标题 24 — 页面标题 20 — 正文 16 — 次要 14 — 辅助徽标 12 — 间距标签 11(`letter-spacing:.08em`,配 ink2,作小节眉标)。AR HUD ≥12 不变。
- 数字(余额/积分/倒计时/百分比):`font-weight:800` + `tabular-nums`;展示字用 `-0.01em` 字距。
- 强对比口径:同屏最大最小字号差 ≥3 档(如 S22:44 vs 11),对标 Zenly 大字特征。

### 7.5 响应式与防横向滚动规范(D-058,硬性验收,原文保留)

- **viewport**:每屏 `<meta name="viewport" content="width=device-width, initial-scale=1">`。
- **自适应容器**:页面容器 `width:100%; max-width:393px; margin:0 auto;`——设计画布 393×852 在大屏居中、小屏(≤393px)铺满;画布高 852px、`overflow:hidden`;**禁止任何 `min-width` 超过视口、禁止固定宽度超过 100% 的元素、禁止负 margin**。
- **溢出源消除**:定位元素只锚单边(left 或 right)+ 流式宽度(`left-0 right-0` + 内部 px 边距),不用「left 偏移 + 固定宽」;flex/grid 子项不设超宽固定宽;长英文串/长数字加 `overflow-wrap:anywhere`(全局 style 已注入);按钮/胶囊用 `shrink-0` + 内容自适应。
- **index.html 画廊**:移动端(≤640px)单列 iframe,iframe 宽 100%;设备壳 `w-full sm:w-[393px]`。
- **验收标准**:视口宽 320/360/393/430px 四档均无横向滚动条、内容完整可见(实现口径:所有宽度只用 100%/max-width/flex,无超宽固定值)。
