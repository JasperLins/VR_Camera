## 📌 文档头契约(下游先读这节)

**关键结论(≤5 条)**
1. **月度总成本**:保守(DAU 1,000)≈ **¥2,300/月**;乐观(DAU 5,000)≈ **¥10,300/月**——均**不含**高德商用「技术服务许可」(约 ¥50,000/年 ≈ ¥4,167/月,见结论 3)。可变成本公式:**月成本 ≈ ¥2.0 × DAU + 固定 ¥255~475**(Meshy 口径)。
2. **3D 生成真实单价(Token 定价校准用)**:Meshy 图生 3D+贴图 **30 credits = $0.60 ≈ ¥4.32/次**(官方文档,高置信);Tripo API $1.00 ≈ ¥7.20/次;Rodin $0.30~0.40 ≈ ¥2.16~2.88/次(第三方平台价,中置信)。含 8% 失败分摊后有效成本 **¥4.70 / ¥7.83 / ¥2.35~3.13**。**PRD 草案「20 Token=¥2/次生成」低于全部三家最低有效成本,全线倒挂**,阶段 7 须上调至 ≥¥5~8/次或明示补贴策略。
3. **地图是最大成本/合规变量**:高德与百度商用授权同价(约 ¥50,000/年);App 一旦开放 Token 现金充值即构成「商业目的」,严格口径需购高德技术服务许可;非商业免费月配额(企业认证:基础 LBS 300 万次/月)仅限 1 年且两档 DAU 用量均可覆盖。
4. 推荐:3D 生成 **Meshy**(对齐 D-014;三家中官方价格透明且低于 Tripo 40%,SSE/Webhook/轮询三通道齐全;**大陆可达性低置信,Sprint-0 实测,备胎 Rodin**);内容审核**阿里云增强版**(1.5 元/千张,比腾讯便宜 40%);地图**维持高德**(费用维度复核通过)。
5. 一次性/年度费用:微信开放平台认证 ¥300/年;ICP 备案 ¥0;算法/深度合成备案官方 ¥0(代办 ¥8,000 起);三家 3D 生成 API 均以美元计费,需国际信用卡支付能力。

**关键假设与置信度**:用量假设式见 §1 各行与 §2 计算式(1% DAU 日生成率、8% 失败率、1.5 次/DAU 日打卡×50% 上传、2 次/DAU 日 AR 会话×净下载 25MB/会话、0.2 条/DAU 日短信);汇率 1 USD=7.2 CNY(假设);单价均附来源与查询日期(§4),Meshy credit 充值单价 $0.02 按官方 Pro 档折算(中高置信)。

**可引用承诺**:§2 两档成本、§3 固定/可变拆分与敏感性公式、每模型真实成本区间(结论 2)可直接被阶段 6(AI 开发计划)与阶段 7(报价/Token 定价校准)引用。

**未决问题**:①Token 收费与高德商用授权时点(见 §5 Q1);②3D 供应商最终确认(Meshy vs Rodin,依赖 Sprint-0 大陆连通性实测,对应技术栈报告 R1);③PRD Token 定价倒挂待阶段 7 校准;④阶段 2/3 标准产物 `feasibility.md`/`feature-list.md` 缺失为**已知欠账**(用量假设暂以项目经理注入口径替代,feature-list 回补后需复核 §1 覆盖面);⑤高德 Unity 旗舰版 SDK 为商务询价制,价格未知(低置信)。

### 1.1 文生 3D 生成 API(Meshy / Tripo / Rodin 三家对比)

**用量假设式(PM 注入口径)**:日生成成功数 = DAU × 1% → 保守 10 个/日、乐观 50 个/日;计费次数(含失败重试)= 成功数 ÷ (1−8%) → 保守 10.9 次/日 ≈ **327 次/月**、乐观 54.3 次/日 ≈ **1,630 次/月**。

| 维度 | Meshy(推荐✅) | Tripo(VAST) | Rodin(Hyper3D/Deemos) |
|---|---|---|---|
| 计费模式 | 订阅+credit 预购(pay-before-you-go);API 需 Pro $20/月起(含 1,000 credits/月) | 按量 credit,1 credit=$0.01,预购 | 订阅(Free/Creator $30/Business $120/月)+按量 credit;官方按量单价未公开标准化 |
| 图生 3D 单价(含贴图) | **30 credits/次=$0.60≈¥4.32**(官方 docs,高置信);不带贴图 20 credits=$0.40 | 约 100 credits/次=$1.00≈¥7.20(官方 developers 页,高置信) | 第三方平台 $0.30~0.40/次(fal.ai $0.40、WaveSpeed $0.30)≈¥2.16~2.88(**中置信**,官方价不透明) |
| 月成本(保守/乐观) | **¥1,410 / ¥7,040**(计算见 §2) | ¥2,376 / ¥11,808 | ≈¥660~880 / ≈¥3,290~4,400(按第三方代理价) |

### 1.3 内容安全审核 API(阿里云 vs 腾讯云,数美简评)

**用量假设式**:机审图片 = 打卡合影上传(1.5 次/DAU/日 × 50% 上传留存 = 0.75 张/DAU/日)+ 生成源照片(0.01 张/DAU/日)≈ 0.77 张/DAU/日;机审文本(留言/命名)0.5 条/DAU/日。保守:图片 22,800 张/月、文本 15,000 条/月;乐观:136,500 张/月、75,000 条/月。峰值 QPS 估算 <5,远低于默认并发。

| 维度 | 阿里云内容安全增强版(推荐✅) | 腾讯云 IMS/TMS(天御) |
|---|---|---|
| 图片审核单价 | **按量 15 元/万张 = 1.5 元/千张**(增强版 2.0,较 1.0 降 50~70%);大模型图片审核 4.5 元/千次 | 按量 25 元/万张 = 2.5 元/千张;套餐 180 万张/¥4,000(≈2.2 元/千张),大客户可至约 10 元/万张 |
| 文本审核单价 | 增强版未单独核实,按 1.5 元/千条估算(**低置信**) | 25 元/万条 = 2.5 元/千条 |
| 免费额度 | **31 天内每日 3,000 张图片 + 3,000 条文本**(≈首月 9 万张免费,覆盖保守档整月) | 首次开通 3,000 张/条试用包,**有效期仅 15 天** |
| QPS | 未核实(文档未标,按量充足) | IMS 默认 100 QPS、TMS 默认 1,000 QPS(官方文档) |

**推荐:阿里云增强版**——单价低 40%、免费期长一倍以上(31 天 vs 15 天)、与 OSS/ECS 同账号体系(OSS 违规检测普惠版 9 元/万次可做兜底扫描)。**为什么不用腾讯云**:单价高且免费期短;**为什么不用数美**:报价制无公开标价、面向中大型客户,初创期不友好(低置信,未询价)。人脸上传另触发敏感个人信息合规义务(PRD 第 7 章,属流程成本非 API 费用)。

### 1.4 对象存储 + CDN(阿里云 OSS 双桶,对齐技术栈报告)

**用量假设式**:GLB 模型均 20MB(PRD 5~50MB 区间中值偏下);打卡照片均 0.8MB(压缩后);内容默认生命周期 30 天后清理(假设,PRD 细节以原文名准);AR 会话净下载 25MB/次(2 个全精度 GLB × 20MB × 50% 客户端缓存命中 + 5MB 地图层预览);照片桶下载 2×上传量(自拍回看+社区浏览)。

| 计费项 | 单价(来源 §4) | 保守(DAU 1,000) | 乐观(DAU 5,000) |
|---|---|---|---|

### 1.6 云服务器/托管

## 3. 汇总

- **月度固定成本合计**:¥255(保守:托管 ¥230+微信 ¥25)~ ¥475(乐观:¥450+¥25);**条件固定**:高德技术服务许可 ¥4,167/月折算(仅商业化后)。
- **可变成本公式(随用量增长,Meshy 口径)**:**月可变 ≈ ¥2.0 × DAU**,构成:3D 生成 ¥1.41(=1%×30×¥4.32÷0.92)+ CDN ¥0.30 + 短信 ¥0.27 + 审核 ¥0.06。等价式:**月总成本 ≈ ¥2.0 × DAU + 固定档**,DAU 10,000 时 ≈ ¥20,500/月(不含地图许可)。
- **敏感性提示**:①**3D 生成率是最大杠杆**——若生成率从 1% 升至 2%,保守档月成本 +¥1,410(总成本近乎翻倍);②CDN 会话流量假设 ±50% → ±¥150(保守)/±¥600(乐观),可用流量包对冲;③**Token 定价红线**:PRD ¥2/生成 < 最低有效成本 ¥2.35(Rodin)——阶段 7 定价须覆盖「生成成本÷(1−8%)+审核/存储/CDN 分摊(约 ¥0.1/次)」,建议生成价 ≥¥5~8;④汇率波动 ±5% → 3D 成本 ±¥70~350/月。
- **盈亏平衡提示(供阶段 7)**:以生成价 ¥5/次计,1% 生成率下毛利 ≈ DAU×30×1%×(5−4.8) ≈ **¥6/月 @DAU1,000**——生成业务本身近零毛利,收入结构须依赖 Token 充值组合与自然流量分摊,或切换 Rodin(有效成本 ¥2.35)拉开毛利。
